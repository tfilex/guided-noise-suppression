# Dataset

The full FMD/AIMD image dataset is not included in this repository. Place the data at:

```text
datasets/AIMD/
```

The paper experiments use the fluorescence microscopy denoising dataset available at:
https://www.kaggle.com/datasets/shiveshcgatech/fluorescence-microscopy-image-denoising-dataset

The fixed train/validation/test partition used in the experiments is stored in
`../splits/fixed_splits.json`.
